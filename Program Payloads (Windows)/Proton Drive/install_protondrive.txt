REM Title: Install Proton Drive via Chocolatey (Admin CMD)
REM Author: CayleRose1
REM Description: Assumes Chocolatey is pre-installed; installs Proton Drive silently and closes terminal

DELAY 1000
GUI r
DELAY 500
STRING cmd
CTRL-SHIFT ENTER
DELAY 1500
STRING choco install protondrive -y && exit
ENTER
